# Portfólio – Davy Caetano

Site estático em HTML, CSS e JavaScript puro.

```
portfolio-site/
  index.html          estrutura e textos (pt-BR)
  css/styles.css      paleta, layout, hero com brilho e animações
  js/main.js          barra de progresso e revelação ao rolar
  assets/img/         imagens WebP usadas no site e favicon.ico
```

## Como abrir
(https://davycaetano08-crypto.github.io/portfolio-pessoal/)

- Ícones: Font Awesome via CDN (script no `<head>` do `index.html`); precisa de internet.
- Fontes: Bricolage Grotesque e JetBrains Mono via Google Fonts.
